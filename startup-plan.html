1. Executive Summary

Mission

Help every runner find their people. Paceway turns "I want to start running with a group" into a 60-second discovery experience — and turns scattered Instagram run clubs into discoverable, joinable communities.

Vision

By 2031, no one in a major running city should ever ask "are there any run clubs near me?" Paceway is the default answer — the way Yelp answered "where should we eat?" and Strava answered "did that run count?"

Core Value Proposition

AudienceCurrent PainPaceway Fix
Runner (18–35)Run clubs feel cliquey, hidden on Instagram, unclear pace/vibeDiscover by pace + vibe + day, RSVP in 1 tap, show up confident
Club OrganizerStuck at 50 IG followers, no growth lever, hard to manage RSVPsGet discovered by nearby runners, manage runs in one place, build legitimacy

Competitive Advantages

  • Founder credibility — Marley is embedded in run culture. Strava is a database, Meetup is a graveyard, IG is a feed. None are run-club-native.
  • Vibe-first UX — pace + social tone + post-run hang info, which no competitor surfaces.
  • Two-sided network with low-cost supply — ~3,000+ active US run clubs; landing 200 wins the category.
  • Timing — the run-club boom (NYT, Vogue, "running is the new going out") is mid-curve, not late.
